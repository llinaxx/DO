# Git vs SVN

## 1. Почему в Git ветвление «дешёвое», а в SVN — «дорогое»?

В Git ветка — это указатель на коммит (несколько байт), создаётся мгновенно.
В SVN ветка — физическая копия директории на сервере, поэтому медленная и тяжёлая.

## 2. Можно ли в SVN сделать коммит без интернета? Почему?

Нет. SVN централизованная: коммиты уходят на сервер. Без сети — нельзя.
В Git коммит делается локально, а push — когда есть сеть.

## 3. В каких сценариях SVN может быть предпочтительнее Git?

- Legacy-проекты с готовой SVN-инфраструктурой.
- Госсектор и банки с централизованным контролем доступа.
- Когда нужен единый центральный репозиторий и не нужна распределённая работа.
